# 量化面试 Coding：先识别操作，再选数据结构

本模块把55个Coding目录条目全部保留在`coding_reviews.json`。现已读到55道原站公开完整题目与解答；最初7道检索未命中的题目，借公开目录ID找到了正常公开题页。其他扩展目录题仍严格区分“查到标题”“读到题目”“读到解答”“执行过检查”，不因已有同族教程就声称读过原题。

一周的目标是：看到常见题，能说清输入输出、保存什么、反复做什么、为何可删去一些候选，并写出基础实现。55题是覆盖地图；本周优先练10–15道代表题，高级流式结构只要求理解为什么简单办法不够。

## 0. 每题都按这六步说

1. **输入→输出。** 是返回一个数、所有组合、索引，还是每笔事件的结果？重复值是否分别计数？区间端点是否包含？
2. **先写能做对的办法。** 枚举哪些候选？每个候选需要多少工作？例如区间有O(n²)个，每次重算总和又多一个n。
3. **决定状态。** 已处理过的数据里，哪些信息足以决定未来？过去全部值不一定需要保存，最小值、频次或最早出现位置可能就够。
4. **找最常见的操作。** 每步都问“有没有”？选哈希；每步取最早/最小？选堆；每步删除最老？选队列；反复求相同子问题？设DP状态。
5. **说明为何可减少候选。** 需要单调性、支配关系、最优子结构或交换论证，不能仅凭“这题像某模板”。
6. **数真实操作。** 两重循环不一定二次，若游标总共只前进n次就是线性；二分后插入Python列表仍要搬动元素，不能只报二分成本。

例：已排序数组找和为T的两个数。输入是升序数组，输出要求先问清。状态为左右游标。最常做一次加法与比较。若最左+最右仍太小，那么当前最左配任何剩余元素都太小，可排除整个当前最左候选；反向同理。每次至少丢掉一个端点，故O(n)。

原站`Two-Sum on a Sorted Array`有特殊契约：只返回指定双指针扫描产生的索引对，不返回所有可行索引对。比如`[1,1,5]`目标6只输出`[0,2]`。因此即使题名熟悉，也先看输出定义。[原题](https://quantvault.org/problem-1234-two-sum-on-a-sorted-array.html)

## 1. 哈希：把“再找一遍”变成“记住并查询”

### 1.1 先弄懂键和值分别代表什么

字典不是万能优化器。键是以后用来查询的条件；值是满足该条件时要保留的信息。

| 以后会问什么 | 键 | 值 |
|---|---|---|
| 某数字出现过没有 | 数值 | 无，集合即可 |
| 某数字出现几次 | 数值 | 频次 |
| 某前缀和最早何时出现 | 前缀和值 | 最早索引 |
| 撤掉某订单 | 订单ID | 可定位/删除的订单节点 |
| 每个交易员累计多少量 | 交易员ID | 累计量 |

“最大值反复倍增”首先练集合查询，但先检查循环能否结束：若输入允许0，且0在集合中，`0→0→0`永远不结束。不要把“几何增长”用于固定点。[原题](https://quantvault.org/problem-2426-maximum-value-after-repeated-doubling.html)

### 1.2 前缀和把一段数据变成两个端点

定义`P[0]=0`，`P[j+1]=a[0]+…+a[j]`，则半开区间`a[i:j]`之和为`P[j]-P[i]`。这个恒等式在有负数时仍成立。

自编例：`a=[2,-1,1,2]`，求和为2的最长连续段。到当前前缀值p，过去需找`p-2`。为了长度最大，同一前缀值只保留最早索引；为了**个数**最多，保存频次；为了最短，可能保存最近索引。目标变了，字典值也要变。

```python
def longest_sum_k(a, target):
    first = {0: -1}
    prefix = best = 0
    for j, x in enumerate(a):
        prefix += x
        if prefix - target in first:
            best = max(best, j - first[prefix - target])
        first.setdefault(prefix, j)
    return best
```

初始`0:-1`表示数组开始前存在空前缀。每个数处理一次，哈希正常分布时为期望O(n)时间、O(n)空间。`setdefault`保留最早位置；改成每次覆盖会使答案变短。QV原题要求最长长度；公开LeetCode560练同一恒等式，但要求**个数**，需改存频次，不能只照抄状态。[公开变体](https://leetcode.com/problems/subarray-sum-equals-k/description/)

范围和计数进一步把等式改成区间查询：`L≤P[j]-P[i]≤U`等价于`P[j]-U≤P[i]≤P[j]-L`。普通哈希只能查某个值，不能直接数值域区间；选读归并计数或离散化Fenwick树，目标O(n log n)。[公开练习LC327](https://leetcode.com/problems/count-of-range-sum/description/)

### 1.3 SQL也是相同的“分组记忆”

QV题名含Transaction Volume，但正文实际要过去30天META**买入笔数+卖出笔数**最多的所有交易员。每行有buyer_id和seller_id，先过滤股票/时间，再用`UNION ALL`把两个角色展开到同一列，按trader_id计数，筛全局最大并保留并列。不能用`UNION`去掉重复角色出现，也不能按股数或净数量求和。窗口函数的计算逻辑在分组之后，SQL可以同一SELECT写`RANK() OVER (ORDER BY SUM(cnt) DESC)`。[原题](https://quantvault.org/problem-1230-top-meta-trader-by-transaction-volume.html)；聚合语义见[PostgreSQL主文档](https://www.postgresql.org/docs/current/queries-table-expressions.html)。

## 2. 双指针与滑窗：只有能证明单调，才不回头

### 2.1 有序合并与三数和

两组按同一复合键`(city,timestamp)`排序的数据，只比较当前两个头部，较小者就是全局下一条。相等时约定先出第一组，可保持每组内部稳定性。每次输出一条并前进一个游标，总计O(n+m)。不用先分城市再排序城市。若要严格控制输出以外的临时空间，尾部也逐条追加，避免Python切片复制剩余数据。

三数和从三层枚举开始：固定第一项后，剩下两项就是有序两数和。排序O(n log n)，n次线性扫描，合计O(n²)。必须区分“不同数值三元组”与“不同索引组合”；去重规则服务于输出要求。

### 2.2 正数区间和：数整片合法起点

自编例`[1,2,1]`，问和严格小于3的区间个数，答案3。扩展右端会增大和，删除左端会减小和。对每个右端，先删到合法，则从left到right的全部起点都合法，一次贡献`right-left+1`。

为何不是两重循环O(n²)？right走n次，left从不回头，总共也只走n次。空间只有窗口和、两个索引与答案。

负数会破坏这条论证：`[5,-4]`且k=3，第一步删掉5后再也回不去，但完整区间和1本来合法。此时改用前缀和与有序统计，而不是勉强保留滑窗。

### 2.3 恰K种值的最短窗口

状态用频次表，不能仅存一个集合，因为移出一个值时要知道窗口中是否仍有其他副本。

自编例`[1,1,2]`、K=2。右端到2时已有两种，先记录长度3；删最左1仍有两种，记长度2；再删1后只剩一种，暂停缩窗。答案2。

```python
def shortest_exact_k(a, k):
    if k <= 0:
        return -1
    counts = {}
    left, best = 0, len(a) + 1
    for right, x in enumerate(a):
        counts[x] = counts.get(x, 0) + 1
        while len(counts) == k:
            best = min(best, right - left + 1)
            old = a[left]
            counts[old] -= 1
            if counts[old] == 0:
                del counts[old]
            left += 1
    return best if best <= len(a) else -1
```

此写法在每轮结束时至多K-1种，新元素至多新增一种，故不会突然越过K。代码已对长度0–6、元素取0/1/2和K=1–4穷举核对。双窗口也可做，但别背错长度：最大的有效左端是`left_(K-1)-1`，长度为`r-left_(K-1)+2`。原页提示有一处少1，正文代码已修正。[原题](https://quantvault.org/problem-1045-shortest-subarray-with-exactly-k-distinct-values.html)

## 3. 堆、双端队列与有序表：按最常用操作选

| 结构 | 适合反复做的操作 | 需要提醒的成本 |
|---|---|---|
| 堆 | 当前最小/最大、插入后仍取最优 | 无法直接取任意秩；删除任意ID要额外索引或惰性删除 |
| deque | 从最老端取、从最新端放 | 不提供按价格排序 |
| 单调deque | 滚动窗口最大/最小 | 索引过期与被更优候选支配是两种删除原因 |
| 排序数组+bisect | 查边界/前驱/后继 | 二分O(log n)，中间插入/删除O(n) |
| 顺序统计树 | 动态保存且查询第k小 | 需维护子树大小与重复计数 |

### 3.1 最少房间和最多任务是两个问题

**最少房间：所有会议必须保留。** 按开始时间排，堆存每间房最近结束时间。若最早空闲时间≤新会议开始则复用，否则开新房。新开时所有旧房都忙，形成所需房间数下界，算法达到该界。

**最多任务：机器数固定，允许放弃任务。** 单机按结束时间最早选，交换论证说明它给未来留下的空间不更少。多机还需找“不晚于开始时刻、且尽量晚腾空”的机器，并不等于弹出最早空闲机器。

自编反例：两机器，任务按结束时刻为`(0,2),(0,3),(3,4),(2,5)`。第三个任务放在3时刻腾空的机器上，留下2时刻腾空的机器给第四个，可全选四个。总选最早空闲机器会把第三个放在2时刻腾空的机器，最后只选三个。

原站多机代码使用Python列表`pop/insort`，所以最坏有O(nm)搬动成本，不能报每次O(log m)。[Python官方说明](https://docs.python.org/3/library/bisect.html)明确区分查找与插入。初学者先练单机选择与最少房间，不要求本周手写平衡树。

### 3.2 滚动极值为何能丢掉一部分历史

维护数值递减的索引deque。新值x到来时，从尾部去掉所有不大于x的旧值：新值更大，而且比旧值更晚过期，旧值此后永远不会成为窗口最大值。再从头部删过期索引，头部就是最大值。每索引入队一次、出队至多一次，O(n)摊还。

这里的证明是“更优且寿命更长”，并非“看起来不重要”。最大回撤还要求峰在谷之前，不能直接拿窗口最大值减窗口最小值。

## 4. 递归、DP与贪心：三种不同的减候选理由

### 4.1 回溯保留所有可能；DP合并相同子问题

24点只有四个数，选两数合成一数就能覆盖不同表达式树。减法、除法要试两个方向。若输入为整数或有理数，用Fraction可避免`23.99999999999999`和24比较的问题。指数搜索在固定四个数上可接受；扩成任意n时不再轻松。

编辑距离的状态是两个前缀`dp[i][j]`。最后一步只能是插入、删除、替换，或相同字符免费对齐。空串边界先写：`dp[i][0]=i, dp[0][j]=j`。表有mn格，每格固定次工作，O(mn)；只求距离时保留两行即可。如果要求编辑路径，要保留重建信息。

### 4.2 恰K段最大和：状态名称比公式更重要

`end[j]`表示“恰用j段，最后一段恰在当前位置结束”；`best[j]`表示“恰用j段，末尾可以在更早位置”。读到x时：

\[
end[j]\leftarrow\max(end[j],best[j-1])+x,\qquad
best[j]\leftarrow\max(best[j],end[j]).
\]

倒序处理j，让右侧`best[j-1]`仍属于上一位置。初始`best[0]=0`，其他为负无穷，确保“恰K个、非空”，而不是偷用空段。自编`[4,-2,5],K=2`选两个单点得9；全负数也必须选，不能返回0。

### 4.3 LIS用支配关系压缩状态

同样长度的上升子序列，末尾更小的那条更容易接未来元素。所以每个长度只保留最小末尾，形成有序`tails`，二分替换，O(n log n)。严格递增用`bisect_left`，否则相同数可能被接长。

`tails`是各长度的代表，未必共同组成一条真实子序列。若要求重建，另存每项前驱和各长度末尾索引。原QV标题含Reconstruction，但页面实际只要求长度；课程明确区分两个版本。

### 4.4 贪心要能交换

苹果装箱的目标是最多**件数**，先取最轻的。若某最优方案取重苹果而漏轻苹果，可交换成轻苹果，不增重量、不减件数；反复交换就得到贪心前缀。这种论证不适用于任意不同价值的背包。

## 5. 图与BFS：把故事翻成点、边、状态

朋友圈是无向图连通分量；岛屿是四邻接网格连通分量；每次从未访问点启动搜索就增加一个分量。入队/入栈时标记，避免同一点被多次排队。邻接矩阵版本检查n²格；网格每格四邻居为O(RC)。递归可能爆栈，Python可先练迭代DFS。

交替移动题的关键不是更复杂的BFS，而是**完整状态**。同一格在偶数时刻只能竖走、奇数时刻只能横走，位置相同不代表未来相同。状态扩成`(row,col,parity)`，每步都翻转奇偶，停留也翻转。共2n²状态、每状态至多三个出口，单位权重BFS为O(n²)。

图搜索通用检查：点是实体还是“实体+资源/时间状态”？边能否走的条件是否只依赖已存状态？权重全1才能直接按BFS层数作为距离。有负权的最短路或汇率套利，是另一套条件，本周只了解转`-log(rate)`后寻找负环的联系。

DAG大量可达查询可选逆拓扑位集传播，先算清n²位空间。一个大整数OR在Python里要遍历多个机器字，不能因为源码只有一个`|`就称常数时间。原页把一般DAG精确可达查询等同于树的DFS时间戳方案缺少必要条件，勿背其复杂度表。

## 6. 量化包装：FIFO、损益和回撤都先定会计口径

### 6.1 FIFO是“最常操作”为弹出最老批次

符号约定买入q>0、卖出q<0。队列中剩余批次应全为同一方向；反方向交易先消耗队首，队首消尽就弹出；交易仍有余量才翻仓成新批次。部分成交不能整批删掉。

自编例，不含手续费：

| 交易(价格,数量) | 本笔已实现 | 累计已实现 | 未平仓 |
|---|---:|---:|---|
| (10,+3) | 0 | 0 | 多3@10 |
| (14,-2) | +8 | 8 | 多1@10 |
| (8,-3) | -2 | 6 | 空2@8 |
| (6,+2) | +4 | 10 | 0 |

已实现曲线`[0,8,6,10]`最大回撤2。若费用“每笔到达即确认”，开仓也要立即扣费；若费用分摊成本，未实现/已实现分配就不同。先写清口径，再实现；不能一部分按文字、一部分按代码。

总时间O(m)的依据是**批次**：每笔最多新建一个批次，每批最多被弹一次；每次匹配若没弹批次，就耗尽当前来单。不是“成交数量为O(m)”。队列最坏O(m)，只有队列外标量是O(1)。

参考实现`coding_checks.py:fifo_demo`使用Decimal并明确费用与异常策略。原站源码的统一`1e-12`阈值会把有效小交易丢掉：买入`7.5e-13`单位、随后价格上涨`1e15`卖掉，正确已实现750，原门槛会使两笔都不留库存、已实现为0。容差须结合交易单位与金额误差约束设计，不可随手设。[原题](https://quantvault.org/problem-524-trade-by-trade-realized-p-l-engine-with-fifo-matching.html)

### 6.2 历史回撤是两个标量；滚动回撤是有序聚合

历史版每个新损益c：先更新peak，再计算`peak-c`，再更新最大dd。初始峰值取0还是首个观测值，会影响一开始为负的序列，必须与题意一致。

滚动版的峰会过期：`[9,1,5]`历史最大回撤8，最后两个点`[1,5]`最大回撤为0。保存历史dd不能撤回过期造成的损失。

对一个时间连续段保存`(max,min,dd)`；先发生的段L与后发生的段R合并：

\[
dd_{L+R}=\max(dd_L,dd_R,\max_L-\min_R).
\]

跨段只允许“左峰→右谷”，不能反过来。这是可结合、不可交换的聚合。用两个栈实现FIFO聚合队列，每元素只搬一次，可得每次O(1)摊还、O(W)空间；线段树给O(log W)最坏更新。环形数组的物理顺序可能不是时间顺序，查询必须按最老到最新合并。实现已对小数组与多个窗口长度穷举核对。

### 6.3 真正流式join要面对“什么时候结果算最终”

温度只在t=1与t=3观测，湿度在t=2观测，t=2的温度只能取t=1最近值，不能看t=3未来。离线排序后合并很直接；乱序流需迟到界、水印、重算/撤回政策。淘汰旧事件也要保留每地每侧最后一个历史基准值供后续向前填充。

无限迟到、有限内存、立即给最终精确结果，三个要求不能同时无条件满足。先把契约说清，比画复杂组件更有价值。

T-Digest仅选读：理解“尾部质心更小、可合并摘要”。原页把尺度导数和允许簇宽关系写反，并给出未成立的一般秩误差保证。正确尺度不变量为非单点簇的`k(q_right)-k(q_left)≤1`；导数在尾部更大，允许的分位跨度更小。簇数/不变量证明不等于GK/KLL式严格秩误差保证。[作者资料](https://github.com/tdunning/t-digest)

### 6.4 一道Coding题也可能先是Bellman方程

Uniform Sampling Game首抽U[0,n]免费，付d可重抽，0<d<n/2。设入场前价值V，继续价值V-d，阈值T=V-d。Bellman方程`V=E[max(U,T)]`给`T+d=n/2+T²/(2n)`，于是`T=n-sqrt(2nd)`，公平价`V=T+d`。n=100、d=8时T=60、公平价68。

原页用停下均值减几何分布重抽费，数学等价，但浮点代码的`n-T`可能舍入为0：n=1、d=1e-40仍满足实数约束，T却舍成1。直接用`n-sqrt(2nd)+d`可避开这次除法。这说明“实数上分母正”不等于“浮点里分母非零”。[原题](https://quantvault.org/problem-2791-uniform-sampling-game-fair-price.html)

### 7.1 基础复杂度要会从操作数得出

线性搜索T(n)=T(n-1)+O(1)，得O(n)。二分T(n)=T(n/2)+O(1)，得O(log n)。归并T(n)=2T(n/2)+O(n)，每层O(n)、log n层，得O(n log n)。Quickselect只进一边，随机枢轴下期望线性，最坏仍可能二次。Master theorem有适用条件，不是看见递归就套。

Fibonacci先从树形重复递归变成两个相邻值滚动更新；再用矩阵平方或快速倍增实现O(log n)次大整数运算。精确F(n)有Θ(n)位，不能把算术操作次数直接当位运行时间。面试先说明固定字长、取模或任意精度模型。

### 7.2 求根时保存的是“根仍在区间里”的证据

连续f且端点异号时可二分。每步半宽，欲使区间宽≤tol，需要大约`ceil(log2((b-a)/tol))`次。m次多项式求值每次用Horner需O(d)，总O(dm)。

自编缩放反例`f(x)=1e-200(x-.25)`：若用`fa*fm≤0`判断异号，乘积下溢成0后可能一直错误选左半边，最后接近0；直接比较两个非零值的符号可避免该乘法。实现还要检查tol>0、中点是否已等于端点，防浮点停滞。Newton局部二次收敛要求简单根、足够近初值等条件；实际常用带包根保障的混合方法。

Softmax同样先做代数变换再运算：设m为最大logit，计算`exp(x-m)`；交叉熵写`(m-x_target)+log(sumexp)`。直接`lse-x_target`在共同大偏移下仍会消去：`[1e16,1e16]`的正确loss为log2，而该写法可得0。

### 7.3 Monte Carlo要同时报告估计与误差

以风险中性GBM无分红为例，欧式到期价格可以一步模拟：`S_T=S_0 exp((r-σ²/2)T+σ√T Z)`，折现后收益样本均值估价格。路径依赖才需要时点网格；时点越密不自动消除所有误差。

独立同分布收益样本且方差有限时，标准误约`s/√M`。将标准误减半通常要4倍路径。固定种子便于重现；再换种子检查稳健性。控制变量用已知均值修正，最优系数依协方差确定；对偶变量是否降方差取决于诱导的协方差，不能假设任何收益都有效。差分Greeks尽量共用随机数，使相近价格估计误差抵消，同时检查步长偏差与噪声。

书中正态拒绝采样若以正半轴指数分布作proposal，先得到的是绝对值分布，还要独立随机符号才有完整标准正态。直接只采正值不可能产生负正态观测。均值、方差公式之外还要检查支持集。

### 7.4 网格更细也可能更不稳定

热方程`u_t=u_xx`显式格式为`u_new[j]=a*u[j-1]+(1-2a)*u[j]+a*u[j+1]`，`a=Δt/Δx²`。标准稳定条件为`0≤a≤1/2`。固定Δt而把Δx减半，a会变4倍，可能失稳；把时间步减小通常有助满足条件。

隐式格式每步解三对角系统，在标准线性热方程设置下可无条件稳定，但仍有精度、边界与一致性要求。“稳定”与“准确”分开；不能对任意PDE笼统说隐式法必然收敛。标准Black–Scholes定价PDE关于期权价值是线性方程。

## 8. 随机算法：正确性来自概率乘法，不来自“看起来随机”

Fisher–Yates在第i步只从未固定的后缀均匀选位置。任一目标排列概率为`1/n×1/(n-1)×…×1=1/n!`。若每步都从全数组随机交换，n=3会有27条等概率执行路径，无法平均分给6个排列，故有偏。

未知长度流采一个位置：第k项以1/k替换候选。老位置此前概率1/(k-1)，再乘存活概率(k-1)/k，变为1/k；新位置也是1/k。重复字符按**位置**均匀，字符值概率由出现频率决定。只记一个候选和计数，不存全流。

位运算用`x>0 and x&(x-1)==0`判断2的幂；缺x>0会把0误认。交换技巧要检查别名：同一存储单元无论XOR还是三步加减都可能归零；签名为引用时不能假装两个变量独立。实际优先标准swap与清楚的代码。
